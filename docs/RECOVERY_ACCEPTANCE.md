## 打开与停止

启动后打开 `http://127.0.0.1:8531`。与日常使用的页面分开，只使用一个验收标签：本服务各标签共享故障控制和合成库。页面侧栏应出现“合成验收控制”和“验收临时目录”。没有这两项就不是本次验收入口。

尚未启动时，在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -m streamlit run scripts/recovery_acceptance.py --server.address 127.0.0.1 --server.port 8531 --server.headless true --browser.gatherUsageStats false
```

在同一终端按 Ctrl+C 停止；不要用日常 `stop.cmd` 停这个不同路径的验收服务。端口被占用时停止本次启动并选择其他空闲端口，同时改用对应地址，不要终止其他服务。没有现成虚拟环境时先按 README 安装依赖；首次安装需要包源，不属于离线运行。

验收数据仅写入被忽略的 `user_data/recovery-acceptance-runs/synthetic-*/`，服务首次加载时新建目录；普通重绘与刷新复用本次目录，重启服务另建一份，不会恢复上次任务。这里的“真实数据”也只是独立的初始空库。保留目录可供核对，请勿复制覆盖日常业务数据库；此入口不提供恢复功能。

每个故障只注入一次。选择故障类型并点击“注入一次故障”；每轮先按页面“重新读取页面”恢复，再开始下一轮。“取消未触发的注入”只取消尚未触发的故障，不会解除页面已有的恢复提示。请用一个浏览器标签完成，以便核对记录数量。

## 1. 页面读取失败与恢复

1. 进入“内容工作区 → 离线草稿”，选 S-02，确认名称与 ID。
2. 在验收控制中选择“下一次页面/预检读取失败”，点击“注入一次故障”。
3. 应只剩固定的数据库错误说明和“重新读取页面”，原内容表单、历史及下载被撤下；不应出现 SQL、堆栈或 `SYNTHETIC_QA_FAILURE`。侧栏控制和导航仍可见。
4. 普通重绘不应自动恢复页面或重新执行动作。点击“重新读取页面”后应恢复到 S-02，无额外业务记录。

- [ ] 桌面通过
- [ ] 窄窗口下提示完整、按钮可点击、导航可展开

## 2. 提交前失败不留下半条事实

1. 仍在 S-02，选择“下一次保存或决定在提交前失败”并注入。
2. 本地操作者填 `qa_manual`，新增一条待核实事实，文本填 `合成验收_提交前失败`，其余保持待核实默认值，点击“保存事实”。
3. 应出现数据库故障说明；不要据此连点保存。
4. 点击“重新读取页面”。该文本不应出现在已保存事实列表；新表单不应自动带回旧事实文本。

- [ ] 无半条记录，恢复未自动重复保存

## 3. 已提交但刷新失败，恢复后只出现一条

1. 选择“下一次保存或决定在提交后刷新失败”并注入。
2. 操作者填 `qa_manual`，新增待核实事实 `合成验收_提交后刷新` 并保存。
3. 故障说明应要求重新读取、核对已保存记录及审计，不应断言“未保存”或“已回滚”。
4. 点击“重新读取页面”：该事实应出现且只有一个事实 ID；在离线草稿页切到“修订历史”标签，展开对应 fact 记录，应有相应创建审计。再重绘一次，数量不能增加。

- [ ] 提交结果说明准确，恢复无重复记录

## 4. 本地决定终态不被重复执行

1. 进入“决策记录 → 本地提案与复盘 → 创建提案”，目标可用合成候选 PC-01。
2. ID 填 `P-MANUAL-01`；前后快照分别填 `合成验收前`、`合成验收建议后`；原因填 `合成验收`；证据填 `fixture://manual/qa`；操作者填 `qa_manual`；预计成本留空。创建提案。
3. 进入“审核与待办”，选择 P-MANUAL-01。注入“下一次保存或决定在提交后刷新失败”。决定选 approved，依据填 `合成人工核对`，操作者填 `qa_manual`，点击“记录本地决定”。
4. 故障后重新读取，应仍定位 P-MANUAL-01，状态为已批准，只可下载人工待办，不再出现“记录本地决定”；审计中有一次创建及一次决定。批准始终不触发外部操作。

- [ ] 原提案定位、终态和审计正确

## 5. 预检局部错误不复用旧确认

1. 进入“数据管理 → 数据导入 → 候选、报价与研究”，点击“预检合成研究示例”，先看到可确认的完整预检，但不提交。
2. 注入“下一次页面/预检读取失败”，再点击一次“预检合成研究示例”。
3. 应显示“预检失败”和重新预检指引；旧差异与“确认并原子提交”入口消失。这里使用预检的局部错误处理，不要求出现全页恢复按钮。
4. 再主动点击“预检合成研究示例”，应得到新批次，可继续核对；不需要提交。

- [ ] 旧预检被撤销，主动重试正常

## 6. 初始化失败仍可备份，空间切换隔离

1. 在合成空间注入“下一次初始化读取失败”，出现故障说明后，从侧栏进入“数据管理 → 数据备份”。
2. 点击“生成本地备份”，应出现独立验收库的快照检查及下载。无需下载或恢复文件。
3. 返回原页面，应仍要求主动重新读取。切换“真实数据”时，验收入口会使用另一个初始为空的独立验收库，旧表单、故障与下载不能带过来，浏览器标题也应对应新空间。
4. 切回合成空间。不要把这里的事实或决定当作真实经营记录。

- [ ] 备份可达，空间隔离及标题正确
