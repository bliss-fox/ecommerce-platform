# 合成数据与验收入口

版本 v0.2 · 2026-10-27

**所有商品、供应商、报价、研究、费用、订单和核验结论均为虚构，仅为开发测试。不是推荐销售的商品，不反映市场行情，不代表已具备销售资质或素材权利。** `fixture://` 是本地测试证据索引，不是真实网站，不应尝试联网访问。

## 基线数据

- `p1/`：3 个候选、6 个报价、3 个 SKU。SKU-03 的获客费为空；Q-03B 的发货费为空；Q-02B 的 MOQ/代发不匹配一单一件。
- `p2/`：7 条研究、7 条候选关联和 15 条检查。只有演示库可接受 synthetic 证据。固定评分时间为 2026-10-27 12:00 上海时间。
- `p4/`：5 条订单，33 条基础费用，3 条广告费分摊，1 条退回回收调整，4 条累计结算快照。P4 金额是独立的历史订单测试输入，不要求等于 P1 当前拟售价。

先加载 P1，再加载 P2 或 P4；各目录作为原子候选变更集预检。P0 只 seed P1，不加载 P2/P4。详细预期见 [验收案例](../ACCEPTANCE_CASES.md)。

## 独立导入场景

**不要把 `import_cases/` 整个目录一键导入。** 每个文件是单独测试，依说明恢复基线或顺序执行：

| 文件 | 前置条件 | 预期 |
| --- | --- | --- |
| products_reordered.csv | 已导入 P1 基线 | 3 行 no-op，记录数不变 |
| product_same_revision_conflict.csv | P1 基线 | 同 revision 内容冲突，整批拒绝 |
| product_revision2.csv | P1 基线 | PC-01 修订为 2，仍只有 3 个候选 |
| product_stale_revision1.csv | 已成功应用 product_revision2 | 旧版本拒绝，不能退回 revision 1 |
| products_atomic_error.csv | P1 基线 | 两行均不写，PC-04 不得半成功 |
| expense_actual_revision2.csv | P4 基线 | OL-04 获客费改为实际 7.00，利润 41.50 |
| settlement_after_refund_revision2.csv | P4 基线 | SET-02 累计到账改为 75.00，待反映退款归零，不累计成 170.00 |

每个成功修订再导入一次应 no-op。错误案例包含明确无效状态，不含真实敏感数据。模板/样例的静态文件检查不等于应用验收测试已通过。
